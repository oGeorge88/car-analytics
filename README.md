## Car Analytics

> **Driving Insights, Empowering Decisions**

Discover trends, visualize data, and make informed automotive decisions with a modern, professional React dashboard.

## 🚗 Features

- **Interactive Dashboard:**
	- Search, sort, and highlight cars with ease
	- Responsive design for all devices
	- Highlighted cars saved to Local Storage
	- Scroll-to-top button for smooth navigation

- **Highlighted Cars Gallery:**
	- View and manage your favorite cars
	- Remove highlights directly from the gallery

- **Comprehensive Statistics:**
	- Tables and charts for car brands and models
	- Interactive pie and stacked bar charts
	- Visual insights into market value and distribution

- **About & Contact:**
	- Professional About page with mission and technology stack
	- Contact page with team info and feedback forms
	- User reviews and feedback stored in Local Storage

- **Modern UI & Accessibility:**
	- Beautiful, accessible, and brand-consistent design
	- Responsive layouts and color schemes
	- Enhanced navigation and footer

## 🛠️ Technology Stack

- React 18
- Vite
- React Bootstrap
- Chart.js & react-chartjs-2
- ESLint (with React, Hooks, and Refresh plugins)

## 🚀 Getting Started

1. **Install dependencies:**
	 ```bash
	 npm install
	 # or
	 pnpm install
	 ```
2. **Run locally:**
	 ```bash
	 npm run dev
	 ```
3. **Build for production:**
	 ```bash
	 npm run build
	 ```
